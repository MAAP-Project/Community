# MAAP Community

This repository is **not a code repository**. It serves as the central hub for collecting community requests, bug reports, feature requests, and data requests for the [MAAP (Multi-Mission Algorithm and Analysis Platform)](https://github.com/MAAP-Project) project.

All code development happens in other repositories within the [MAAP-Project](https://github.com/MAAP-Project) organization.

## How to Use This Repository

### Issues

Use the [Issues tab](https://github.com/MAAP-Project/Community/issues) to submit:

- **Bug reports** — something isn't working as expected
- **Feature requests** — ideas for new capabilities
- **Data requests** — requests for datasets to be made available on the platform

### Project Board

Track the progress of community requests on the [MAAP Community Project Board](https://github.com/orgs/MAAP-Project/projects/5).

### Pull Requests

The [Pull Requests tab](https://github.com/MAAP-Project/Community/pulls) is only used for updates to how this repository itself is structured (e.g., issue templates, documentation). Code development is done in other MAAP repositories.
